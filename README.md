# MAXGRAND — 高科技風格網站重製 / High-Tech Website Redesign

以現代高科技風格重新製作 [maxgrand.com.hk](https://maxgrand.com.hk)（香港領先照明供應商，成立於 1992 年）的形象網站。

A modern, futuristic redesign of the Maxgrand Limited corporate website.

## ✨ 特色 Features

- **深色未來感設計** — 霓虹青／琥珀光效配色，呼應「照明」主題
- **互動粒子光網背景** — Canvas 粒子連線動畫，滑鼠靠近時發光
- **玻璃擬態導覽列** — 毛玻璃模糊 + 掃描光暈
- **中英雙語切換** — 一鍵切換繁體中文／English
- **動態數據計數器** — 滾動觸發的統計數字動畫
- **光束 Hero 動畫** — 象徵燈光從天而降的光柱效果
- **品牌跑馬燈** — FLOS、ewo、Linea Light 等國際品牌展示
- **卡片聚光燈效果** — 滑鼠追蹤的 radial 光暈
- **完全響應式** — 支援桌面／平板／手機
- **零依賴** — 單一 HTML 檔案，純原生 CSS/JS，無需建置

## 🚀 使用 Usage

直接以瀏覽器開啟 `index.html`，或部署至任何靜態網站託管（GitHub Pages、Netlify、Vercel）。

```bash
# 本地預覽
python3 -m http.server 8000
# 開啟 http://localhost:8000
```
